SITE PERITO - TESTE GITHUB PAGES

2. Extraia este ZIP e envie o conteudo para a raiz da branch main.

4. Acesse https://decioalmeida2022.github.io/site-perito-rafael/

Nao incluir admin.html, salvar.php ou credenciais.
